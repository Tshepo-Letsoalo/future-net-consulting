## 💡 About The Project

**FutureNet Consulting** is a professional tech services platform designed and developed to deliver reliable computer repairs, cellphone fixes, hardware installations, and modern web solutions to clients in Mankweng and surrounding areas. 

Built with performance, modern styling, and user experience in mind, the platform features a responsive glassmorphism design, multi-page layout, and an integrated backend messaging pipeline for client inquiries.

---

## 🛠️ Built With & Technologies

* **Frontend:** HTML5, CSS3 (Custom Glassmorphism Styling), JavaScript (ES6+)
* **Form Backend:** Web3Forms API (Direct-to-Email Inquiry Routing)
* **Hosting & Deployment:** Vercel (Continuous Deployment via GitHub)
* **Design & Prototyping:** Responsive Mobile-First Architecture

---

## ✨ Key Features

* 📱 **Direct WhatsApp Integration:** Quick click-to-chat features connecting customers instantly to technicians.
* 📩 **Interactive Repair Inquiries:** Secure, serverless contact form routing messages straight to professional email inboxes.
* 🗺️ **Local Service Maps:** Embedded Google Maps location mapping for easy storefront/service area reference.
* 📱 **Fully Responsive Layout:** Optimized seamlessly across mobile phones, tablets, and desktop workstations.
